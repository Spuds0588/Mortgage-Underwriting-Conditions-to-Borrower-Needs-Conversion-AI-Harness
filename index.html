This harness runs on Chrome's built-in LanguageModel API (Gemini Nano). You appear to be using a browser or profile without it. To enable it:

  1. Use Google Chrome (v138+ recommended, stable channel).
  2. Open chrome://flags/#prompt-api-for-gemini-nano → set to Enabled.
  3. Open chrome://components → find Optimization Guide On Device Model → click Check for update (wait for it to fully download, ~2 GB).
  4. Relaunch Chrome and reopen this page.

For real on-device inference without Nano, pick the WebLLM or Transformers.js engine below — both run compact LLMs fully in this browser.
