# Mortgage-Underwriting-Conditions-to-Borrower-Needs-Conversion-AI-Harness
a lightweight, zero-dependency, open-source test bench demonstrating the viability of in-browser Local Large Language Models (LLMs). The tool will ingest loan underwriting conditions (clean or messy), extract individual conditions, and translate them into client-friendly needs using Chrome's built-in Gemini Nano API.
